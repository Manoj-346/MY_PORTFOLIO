# Manoj Nakka — Student developer portfolio

A responsive portfolio built with HTML, CSS, and vanilla JavaScript. Open `index.html` directly in a browser or serve this folder with a static file server.

## Profile and motion

- The resume content and contact details are in `index.html`.
- The profile photo is stored at `assets/manoj-profile.png` and rotates continuously in the hero.
- The `View CV` link opens `assets/Manoj-Nakka-Resume.pdf`.
- `motion.css` and `script.js` provide scroll reveals, project card tilt, and scroll progress.
- Reduced-motion preferences disable the continuous spin and soften reveal motion.

Confirm contact and social links before publishing. Add repository or live-demo links to the project cards when available.

The page uses Google Fonts when online and falls back to system fonts otherwise.
